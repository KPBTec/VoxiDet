Comportamiento:
  • DENY — bloquea la IP en la red (antes de que llegue a la aplicación)
  • ALLOW + SSH — whitelista la IP para SSH. Si hay alguna regla SSH-allow, el resto queda bloqueado
  • ALLOW + API — whitelista la IP para el puerto 8000. Si hay alguna regla API-allow, el resto queda bloqueado
  • Sin reglas API: el puerto 8000 queda abierto, protegido solo por API key
  • Los cambios se aplican inmediatamente vía nftables
